Agents lie.
My systems check.

I build the enforcement layer around fleets of AI coding agents: leases, frozen tests, adversarial review, and audits of my own rules.

01

The fleet

One model orchestrates, others implement and review, each task routed by how much judgment it needs. The interesting engineering is the guardrails: write leases handed out at dispatch so agents never fight over a worktree, acceptance tests frozen before the implementer sees them, and a permission model where commit doesn't imply push and push doesn't imply PR.

It exists because one review prompt once spawned 928 recursive subagents. The fix wasn't a warning in a doc. It was moving delegation caps into config an agent can't argue with.

02

Gateway fork

Forked an open-source agent gateway and built its missing enforcement layer: checkpointing with claim fencing, a fail-closed capability handshake, comment-driven wake for blocked work. Rebased a shallow clone that turned out to be 508 commits behind upstream before touching anything.

Proved the branch clean with a differential sweep. Branch and base failed identically, roughly 605 pre-existing environmental failures each, zero caused by the diff.

03

The audit

I mined every agent transcript on my machine to test whether my agents follow my rules or I just believe they do. First pass had broken methodology (replay copies, double-logged prompts), so I threw it out and redid it. Kept the caveat that the rules postdate most of the data, so the data can't flatter them.

04

Tools

pi-ui, a terminal browser that resumes live sessions from three different agent CLIs over a PTY. A two-phase review pipeline where the model that wrote the code is never its only reviewer. A screen-by-screen parity differ that turns "the upgrade changed nothing" from a vibe into a diff.
