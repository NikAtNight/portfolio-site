# Portfolio

Static site at https://nikhilkapadia.pages.dev, Cloudflare Pages project `nikhilkapadia`.

- Source of truth is `index.html` at the repo root. `dist/` is a generated upload set and is gitignored; never edit it by hand.
- `functions/` holds a Pages Function (contribution chart). It deploys with the site.
- Deploy with `./deploy.sh`. The Pages project is not Git-connected, so a push never deploys. Run the script only when Nikhil asks for a deploy.
- Side Quests in `index.html` stay in alphabetical order.
- Commit and push only when asked.
